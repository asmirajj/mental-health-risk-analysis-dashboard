# 🧠 Mental Health Analysis Dashboard

This project is an interactive Tableau dashboard designed to analyze mental health risks based on lifestyle factors, such as sleep, exercise, and job satisfaction. The goal is to provide insights into mental health patterns and detect early warning signs.

## 📊 Features

- **Dynamic Filtering**: Filter data by various lifestyle factors like sleep, exercise, and job satisfaction.
- **Trend Analysis**: Visualize trends in mental health across different age groups, genders, and more.
- **Risk Identification**: Quickly identify potential early signs of mental health concerns.
- **Interactive Interface**: User-friendly and accessible interface for quick data analysis.

## 💡 Tools & Technologies

- **Tableau** (Data Visualization)
- **Microsoft Excel** (Dataset preparation)
- **Data Cleaning & Transformation** (Basic pre-processing in Excel)

## 📁 Files

- `mental_health_dashboard.twb` – Tableau workbook file that powers the dashboard.
- `dataset.xlsx` – The dataset used in the analysis.
- `screenshots/` – A folder containing various screenshots of the dashboard for preview.
